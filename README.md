# Womendetention — сайт

Статический двуязычный сайт (EN / RU). Только HTML, CSS и vanilla JS, без сборки.
Работает на GitHub Pages как есть.

## Структура

```
/index.html        английская версия (главная)
/ru/index.html     русская версия
/privacy.html      политика конфиденциальности, EN (заглушка)
/ru/privacy.html   политика конфиденциальности, RU (заглушка)
/style.css         общий стиль для всех страниц
/script.js         мобильное меню, год в футере, плавный скролл
/assets/
  logo.jpg              эмблема на первом экране (640px)
  logo-small.jpg        маленький логотип в шапке
  favicon.png           иконка вкладки браузера
  apple-touch-icon.png  иконка при добавлении на экран телефона
  logo-original.webp    исходник эмблемы (на сайте не используется)
  about.svg             иллюстрация-заглушка в блоке «О нас»
/CNAME             домен для GitHub Pages (womendetention.com)
```

## Как редактировать

- **Тексты** правятся прямо в HTML. Английские в `index.html`, русские в
  `ru/index.html`. Секции подписаны комментариями (`<!-- ===== HERO ===== -->` и т.д.).
  Если меняешь текст на одном языке, поправь и второй файл.
- **Ссылки-заглушки** помечены `<!-- TODO: ... -->`. Найти их все можно поиском по `TODO`.
- **Цвета и размеры** задаются в начале `style.css` в блоке `:root`.
  Например, `--color-accent` — цвет кнопок.
- **Логотип**: эмблема круглая, белые углы обрезаются в CSS (`border-radius: 50%`).
  Чтобы заменить, перезапиши `assets/logo.jpg` и `assets/logo-small.jpg` файлами с теми же именами.
- **Картинка в «О нас»**: замени `assets/about.svg` на фото (лучше `.jpg`
  шириной около 1200px) и обнови `src` и `alt` в обоих HTML.
- В `ru/index.html` все пути к общим файлам начинаются с `../`
  (`../style.css`, `../assets/...`). Это нормально.

## Адаптивность

Стили написаны mobile-first. Контрольные ширины в `style.css`:
- до 359px — маленькие телефоны (уменьшенная шапка);
- 640px — кнопки в ряд;
- 768px — планшет: эмблема справа от заголовка, «О нас» в две колонки;
- 900px — десктоп: меню в строку вместо «гамбургера», три карточки в ряд;
- 1440px — широкие экраны: шире контейнер, чуть крупнее текст.

## Просмотр локально

Открой `index.html` в браузере двойным кликом. Сервер не нужен.

## Деплой на GitHub Pages

1. Создай репозиторий на GitHub и загрузи в него все файлы (в корень).
2. Settings → Pages → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Файл `CNAME` уже содержит `womendetention.com`, адреса в `canonical`/`hreflang` тоже прописаны.
4. В Squarespace (Domains → DNS settings) добавь записи:
   - `A` для `@`: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
   - `CNAME` для `www`: `<твой-логин>.github.io`
5. В Settings → Pages укажи Custom domain и, когда DNS обновится
   (от нескольких минут до 24 часов), включи **Enforce HTTPS**.
